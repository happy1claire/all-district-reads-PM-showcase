# All-District Reads

📘 **Product Manager Portfolio Project**  
Built for [Hack4Impact](https://umd.hack4impact.org/ourwork/adr)

## 🔍 My Role

- Spearheaded development of a mobile app and web platform to support literacy education across school districts
- Led a cross-functional team of 14 engineers and designers
- Authored Product Requirement Documents (PRDs) and user stories based on stakeholder interviews
- Collaborated with engineers to scope features, prioritize bugs, and review GitHub pull requests

## 🛠 Technologies Used
- React Native
- Firebase
- GitHub
- Notion
- Figma
